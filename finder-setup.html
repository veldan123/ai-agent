Set up Client Finder AI

Tell it your profession, it figures out who needs your service and finds their contact emails — automatically.

1

Open Terminal

Press Cmd + Space, type Terminal, press Enter.

2

Paste this command and press Enter

It installs everything automatically — Python, Ollama, the AI model, and the agent. First run takes ~5–10 min. Already have some installed? No problem, it skips what's already there.

curl -fsSL https://raw.githubusercontent.com/veldan123/ai-agent/main/install_finder_mac.sh | bash

The agent will launch in Terminal and ask what business you're in.

3

Open it again anytime

Open Terminal and run:

python3 ~/contact_finder/agent.py

Choose what to install

Python 3 Required
Needed to run the agent. Uncheck if Python 3 is already installed. Make sure "Add Python to PATH" was ticked during install.
Ollama Required
Runs the AI locally. Uncheck if Ollama is already installed on your PC.
AI Model — qwen2.5:7b ~4 GB Required
The AI brain. Only downloaded once. Uncheck if you've already pulled qwen2.5:7b in Ollama.
Client Finder Agent Always included
The AI agent script that finds client contacts — always downloaded and launched.

After downloading

1

Find the downloaded file

Look in your Downloads folder for install_finder.bat.

2

Right-click it → Run

Do not double-click — if VS Code is installed it will open the file instead of running it.

Instead: right-click the file → select "Open with" → "Windows Command Processor". A black window will open and run the installer automatically.

💡 If you see a blue SmartScreen warning → click More info → Run anyway.
3

Run again anytime

Right-click install_finder.bat → "Open with" → "Windows Command Processor".
