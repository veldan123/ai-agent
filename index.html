What it does

🧠

Thinks like a salesperson

Tell it you're a photographer — it figures out who needs one (wedding planners, real estate agents, cafes) instead of finding other photographers.

🔍

Dorks the web automatically

Runs dozens of search queries across hundreds of websites to surface publicly available email addresses and phone numbers.

✉️

Filters junk emails

Removes noreply@, wordpress@, bounce@, and other non-emailable addresses. Only keeps real inboxes someone will actually read.

📋

Exports to CSV + clipboard

Results saved to a CSV file and copied to your clipboard automatically. Paste straight into Excel, Google Sheets, or your CRM.

🆓

Completely free

Runs a local AI model via Ollama on your Mac. No API key, no subscription, no data sent to the cloud.

⚡

You stay in control

Choose which client types to target, how many websites to scan, and add extra filters before the search starts.

How to get started

1

Download the files

Click the download button above. Unzip the folder and move it anywhere on your Mac (Desktop is fine).

2

Install Ollama (the free AI)

Download the Ollama app from ollama.com/download and open it. You'll see a small icon in your menu bar.

3

Download the AI model (once)

Open Terminal and run:

ollama pull qwen2.5:7b

This downloads the free AI model (~4GB). Only needs to happen once.

4

Install Python dependencies

In Terminal, run:

python3 -m pip install -r requirements.txt
5

Run the agent

In Terminal, run:

python3 agent.py

Tell it what you do and watch it find clients for you.
