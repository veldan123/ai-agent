Now let's get you set up

Follow these 5 steps and you'll be finding clients in under 10 minutes.

1

Unzip the downloaded file

Find ai-agent-main.zip in your Downloads folder. Double-click it to unzip. You'll get a folder called ai-agent-main.

2

Install Ollama Free One-time

Ollama is the free app that runs the AI on your Mac. Download and open it — you'll see a small icon appear in your menu bar (top right of screen).

⬇ Download Ollama
3

Download the AI model One-time · ~4GB

Open Terminal (press Cmd+Space, type Terminal, press Enter). Then paste this command:

ollama pull qwen2.5:7b

This downloads the free AI model. Only needs to happen once.

4

Install dependencies One-time

In Terminal, navigate to the unzipped folder and install the required packages:

cd ~/Downloads/ai-agent-main
python3 -m pip install -r requirements.txt
5

Run the agent

In Terminal, run:

python3 agent.py

Tell it your profession and location — it will find potential clients for you automatically.

You're all set!

Every time you want to use the agent, just open Terminal and run:

python3 ~/Downloads/ai-agent-main/agent.py
