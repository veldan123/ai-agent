Set up AI Script Writer

Describe what you want — AI writes a complete, working Python, Bash, JavaScript, or HTML file, checks it for errors, and saves it ready to use on your computer.

1

Open Terminal

Press Cmd + Space, type Terminal, press Enter.

2

Paste this command and press Enter

It installs everything automatically — Python, Ollama, the AI model, and the tool. First run takes ~5–10 min. Already have some installed? It skips what's already there.

curl -fsSL https://raw.githubusercontent.com/veldan123/ai-agent/main/install_script_writer_mac.sh | bash

It'll ask what the script should do and which language to use — then it writes the code, checks that it's valid, and saves it ready to run.

3

Open it again anytime

Open Terminal and run:

python3 ~/script_writer/agent.py
💡 Already installed? Re-run the command from step 2 to update to the latest version.

Choose what to install

Python 3 Required
Needed to run the tool. Uncheck if Python 3 is already installed. Make sure "Add Python to PATH" was ticked during install.
Ollama Required
Runs the AI locally. Uncheck if Ollama is already installed on your PC.
AI Model — gemma3:4b ~3 GB Required
The AI brain that writes your scripts. Only downloaded once. Uncheck if you've already pulled gemma3:4b in Ollama.
AI Script Writer Always included
The tool itself — always downloaded and launched.

After downloading

1

Find the downloaded file

Look in your Downloads folder for install_script_writer.bat.

2

Right-click it → Run

Do not double-click — if VS Code is installed it will open the file instead of running it.

Instead: right-click the file → select "Open with" → "Windows Command Processor". A black window will open and run the installer automatically.

💡 If you see a blue SmartScreen warning → click More info → Run anyway.
3

Run again anytime

Right-click install_script_writer.bat → "Open with" → "Windows Command Processor".
