1

Download the files

Click below to download. Then find ai-agent-main.zip in your Downloads folder and double-click to unzip it.

⬇
Download for Mac
ai-agent-main.zip
2

Double-click the installer Installs everything automatically

Open the unzipped folder → go into chatbot_app → double-click install_mac.command.

A Terminal window will open and handle everything — Python, Ollama, AI model download, and launching the app. First run takes ~5–10 minutes.

💡 If Mac says "can't be opened", right-click the file → Open → Open again.

You're all set!

The chatbot app window opens automatically after setup.
To open it again later, just double-click install_mac.command again.

1

Download the files

Click below to download. Then find ai-agent-main.zip in Downloads, right-click → Extract All.

⬇
Download for Windows
ai-agent-main.zip
2

Install Python One-time

Download from python.org/downloads. During install, tick "Add Python to PATH" — this is important!

3

Install Ollama One-time

Download and install from ollama.com/download.

4

Run the installer Sets up everything

Open the unzipped folder → go into chatbot_app → double-click install_windows.bat.

It downloads the AI model (~4GB, one-time) and launches the app automatically. First run takes ~5–10 minutes.

You're all set!

The chatbot app window will open automatically after setup.
To open it again later, double-click install_windows.bat or run:

python chatbot_app.py
